# OpenWrt Script Manager

Веб-менеджер пользовательских shell-скриптов для OpenWrt.

## Возможности

- список `.sh`-скриптов из `/etc/my_scripts`;
- создание и редактирование скриптов;
- запуск скрипта вручную;
- удаление скрипта вместе с его cron-записью;
- расписание через понятный интерфейс без знания синтаксиса cron:
  - при запуске OpenWrt — вариант по умолчанию;
  - через интервал;
  - каждый день в указанное время;
  - по выбранным дням недели;
- после сохранения скрипт автоматически включается в cron;
- переключатель включения/отключения cron остаётся в списке скриптов;
- проверка новых сборок GitHub при открытии панели;
- ручная проверка обновлений и обновление из GitHub;
- отдельный uhttpd на порту `9696`;
- HTTP Basic Auth через uhttpd;
- POSIX `/bin/sh` backend;
- без внешних CDN и JS-фреймворков.

## Автозапуск

Установщик включает экземпляр `uhttpd.script_manager` в автозапуск OpenWrt.
Дополнительно устанавливается cron-запись `@reboot` для запуска uhttpd Script Manager.

Вариант расписания «При запуске OpenWrt» использует `@reboot`.
Он требует поддержки special times в BusyBox `crond`; если конкретная сборка OpenWrt её не включает, сам uhttpd всё равно запускается штатным механизмом init.

## Установка

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/Ve5os/openwrt-script-manager/main/install.sh)"
```

После установки панель доступна на:

`http://<router_ip>:9696`

## Файлы

```text
/etc/my_scripts/                 пользовательские скрипты
/etc/crontabs/root               cron-задания
/www-script-manager/             web-интерфейс и CGI
```
