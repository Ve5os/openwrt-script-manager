# OpenWrt Script Manager

Веб-панель для создания, редактирования и запуска shell-скриптов на OpenWrt.

Панель позволяет хранить скрипты в `/etc/my_scripts`, запускать их вручную и настраивать cron без необходимости писать cron-выражения вручную. Для опытных пользователей есть ручной режим, где cron можно указать самостоятельно.

## Установка

Подключитесь к роутеру по SSH под `root` и выполните:

```sh
wget -O - https://raw.githubusercontent.com/Ve5os/openwrt-script-manager/main/install.sh | sh
```

После установки откройте:

```text
http://IP_РОУТЕРА:9696
```

Логин: `root`

Пароль: пароль пользователя `root` на роутере.

## Как пользоваться

### Создать скрипт

1. Нажмите **Новый скрипт**.
2. Укажите имя без `.sh` — например `backup`.
3. Напишите shell-скрипт.
4. Выберите расписание.
5. Нажмите **Сохранить**.

После сохранения скрипт автоматически включается в cron.

### Расписание

Доступны четыре режима:

- **При запуске OpenWrt** — запускает скрипт при загрузке роутера. Это режим по умолчанию (`@reboot`).
- **Через интервал** — запуск через заданное количество минут, часов или дней.
- **Каждый день** — запуск в указанное время.
- **По дням недели** — запуск в выбранные дни и время.
- **Ручной cron** — для точной настройки. В поле можно написать своё cron-выражение, например `*/15 * * * *`.

### Включение и отключение

Переключатель рядом со скриптом в левом списке включает или отключает его выполнение по cron. Сам файл при этом не удаляется.

### Выполнить сейчас

Откройте скрипт и нажмите **Выполнить сейчас**, чтобы запустить его сразу. Результат выполнения появится в панели.

### Удаление

Кнопка **Удалить** удаляет скрипт и его cron-запись.

## Обновление

Панель автоматически проверяет наличие новой версии при открытии. Проверить вручную можно кнопкой `↻` рядом с номером сборки слева сверху. Если доступна новая версия, появится кнопка **Обновить**.

Обновление скачивает официальный `install.sh` из репозитория и устанавливает новую версию поверх текущей. Пользовательские скрипты из `/etc/my_scripts` не удаляются.

## Где находятся файлы

- Скрипты: `/etc/my_scripts`
- Cron: `/etc/crontabs/root`
- Веб-панель: `/www-script-manager`
- API: `/www-script-manager/cgi-bin/api.sh`
- Панель: `http://IP_РОУТЕРА:9696`
