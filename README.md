# OpenWrt Script Manager

Build: 2026.11.19.03

## Новое

- В верхней части панели вместо OpenWrt показывается номер текущей сборки.
- Рядом есть кнопка ручной проверки обновлений.
- При открытии панели выполняется автоматическая проверка GitHub.
- При наличии новой сборки появляется предложение обновиться.
- Обновление скачивает официальный `install.sh` из репозитория и выполняется автоматически от root.
- После обновления uhttpd перезапускается, а браузер автоматически перезагружает панель.
- Предыдущие функции менеджера сохранены.
