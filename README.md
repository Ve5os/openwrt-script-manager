# OpenWrt Script Manager

Веб-менеджер пользовательских shell-скриптов для OpenWrt.

## Зачем нужен этот проект

OpenWrt Script Manager создан для того, чтобы управлять небольшими shell-скриптами на роутере через удобную веб-панель, не заходя каждый раз в SSH и не редактируя cron вручную.

Можно создавать, редактировать, запускать и удалять `.sh`-скрипты, а расписание задавать обычными понятными параметрами: выбрать запуск при старте OpenWrt, интервал, время или дни недели. При этом сам менеджер автоматически создаёт и изменяет соответствующие записи cron.

Проект рассчитан прежде всего на OpenWrt и использует только штатные возможности системы: `uhttpd`, BusyBox `crond`, POSIX `/bin/sh` и обычный HTML/CSS/JavaScript без внешних CDN и фреймворков.

## Возможности

- список `.sh`-скриптов из `/etc/my_scripts`;
- создание и редактирование скриптов;
- запуск скрипта вручную;
- удаление скрипта вместе с его cron-записью;
- автоматическое включение скрипта в cron после сохранения;
- включение и отключение cron для скрипта из списка;
- понятный планировщик без необходимости знать синтаксис cron:
  - **При запуске OpenWrt** — вариант по умолчанию;
  - **Через интервал** — например, каждые 1 час или каждые 5 минут;
  - **Каждый день** — запуск в указанное время;
  - **По дням недели** — выбор конкретных дней и времени;
- автоматическое создание корректной cron-записи;
- удаление старой cron-записи при изменении расписания;
- проверка новых сборок GitHub при открытии панели;
- ручная проверка обновлений;
- обновление Script Manager прямо из веб-панели;
- отдельный экземпляр `uhttpd` на порту `9696`;
- HTTP Basic Auth через `uhttpd`;
- POSIX `/bin/sh` backend;
- без внешних CDN и JS-фреймворков;
- идемпотентная установка — повторный запуск установщика не должен создавать дубликаты конфигурации.

## Как это работает

Пользовательские скрипты хранятся отдельно от самого веб-приложения:

```text
/etc/my_scripts/
```

Cron-задания находятся в стандартном файле OpenWrt:

```text
/etc/crontabs/root
```

Веб-панель работает через отдельный `uhttpd` на порту `9696`, поэтому она не заменяет и не ломает стандартную LuCI-панель OpenWrt.

При сохранении скрипта менеджер записывает его в `/etc/my_scripts/` и автоматически добавляет/обновляет его расписание в `/etc/crontabs/root`.

## Расписание

### При запуске OpenWrt

Это стандартный вариант для новых скриптов.

Он создаёт cron-задание вида:

```cron
@reboot /etc/my_scripts/example.sh
```

То есть скрипт запускается при старте системы, если используемая сборка BusyBox `crond` поддерживает special times (`@reboot`).

### Через интервал

Позволяет выбрать период без написания cron вручную.

Например:

```text
Каждые 5 минут
Каждый 1 час
Каждые 6 часов
```

### Каждый день

Можно выбрать конкретное время, например:

```text
03:00
18:30
23:45
```

### По дням недели

Можно выбрать нужные дни и время, например:

```text
Понедельник, Среда, Пятница — 20:00
```

## Автозапуск самого Script Manager

Сам Script Manager должен быть доступен после перезагрузки роутера без ручного запуска.

Поэтому установщик:

1. создаёт отдельный экземпляр `uhttpd` для панели;
2. включает его через штатный механизм автозапуска OpenWrt;
3. дополнительно создаёт cron-запись `@reboot` для запуска Script Manager.

Таким образом, после перезагрузки OpenWrt веб-панель снова должна быть доступна по адресу:

```text
http://<IP-адрес-роутера>:9696
```

Для конкретной сборки OpenWrt поддержка `@reboot` зависит от конфигурации BusyBox `crond`. Даже если `@reboot` недоступен, штатный автозапуск `uhttpd` остаётся основным механизмом запуска самого Script Manager.

## Установка

Установка выполняется непосредственно на роутере через SSH от `root`.

Выполните:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/Ve5os/openwrt-script-manager/main/install.sh)"
```

Установщик автоматически создаёт необходимые каталоги, конфигурацию `uhttpd`, CGI API, web-интерфейс и настройки автозапуска.

### После установки

Откройте в браузере:

```text
http://<router_ip>:9696
```

Например:

```text
http://192.168.1.1:9696
```

Авторизация выполняется через HTTP Basic Auth `uhttpd`.

## Обновление

В верхней части панели отображается текущий номер сборки.

При открытии панели Script Manager автоматически проверяет GitHub на наличие новой версии.

Если новая сборка найдена, появляется предложение обновиться. Также обновление можно проверить вручную кнопкой рядом с номером сборки.

При запуске обновления Script Manager скачивает официальный `install.sh` из репозитория и запускает его после завершения текущего HTTP-запроса. Это позволяет обновить саму панель без ручного подключения по SSH.

Источник обновлений:

```text
https://github.com/Ve5os/openwrt-script-manager
```

Установщик использует `BUILD_VERSION` из `install.sh` как номер актуальной сборки.

## Основные файлы на роутере

```text
/etc/my_scripts/                 пользовательские shell-скрипты
/etc/crontabs/root               cron-задания root
/www-script-manager/             web-интерфейс и CGI
/etc/config/uhttpd                конфигурация uhttpd
/etc/init.d/uhttpd                 запуск uhttpd
```

## Требования

- OpenWrt 24.x и совместимые версии;
- `uhttpd`;
- BusyBox `crond`;
- `wget` для загрузки установщика и обновлений;
- `jsonfilter` желательно, но backend имеет fallback для разбора простых JSON-запросов;
- доступ к GitHub для проверки и установки обновлений.

## Безопасность

Панель защищается HTTP Basic Auth средствами `uhttpd`.

Пользовательские имена скриптов ограничиваются форматом:

```text
^[a-zA-Z0-9_-]+\.sh$
```

Backend не использует `eval` для выполнения пользовательских команд.

Скрипты запускаются по абсолютному пути без передачи аргументов:

```text
/etc/my_scripts/<script>.sh
```

При изменении файлов используются временные файлы и атомарная замена там, где это необходимо.
