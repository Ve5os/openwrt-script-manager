# OpenWrt Script Manager

Build: 2026.11.19.01

Standalone web panel for OpenWrt.

## Что изменено в этой сборке

- Переключатель включения/выключения cron перенесён непосредственно в список скриптов.
- Переключатель находится справа от имени каждого скрипта.
- Нажатие на переключатель не открывает редактор скрипта.
- При переключении используется текущее расписание этого скрипта.
- Основной переключатель в редакторе сохранён.
- Все предыдущие функции Build 2026.11.18.04 сохранены.
